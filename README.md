# Previsão da Qualidade da Água via Sensoriamento Remoto

Esta proposta descreve um plano para desenvolver uma aplicação que prevê parâmetros de qualidade da água em reservatórios usando imagens de sensoriamento
remoto e modelos de machine learning. O foco é a definição do problema, metodologia de desenvolvimento e avaliação, expectativas de resultado e cronograma de
desenvolvimento
